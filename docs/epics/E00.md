## Goal
Monorepo, dev mühiti və bütün GitHub avtomatlaşdırması işlək vəziyyətə gətirilsin ki, qalan epic-lər
yalnız məhsul kodu yazsın: hər PR avtomatik yoxlanılsın, board özü yenilənsin, icazəsiz asılılıq keçməsin.

## Scope
- Monorepo skeleti, `README.md`, `.gitignore`
- Bütün servislər üçün dev `docker-compose`
- `main` üzərində ruleset + təhlükəsizlik parametrləri
- "GitHub automation" bölməsindəki bütün workflow-lar
- Dependabot, `CODEOWNERS`, `dependency-guard` + allowlist
- Issue/PR şablonları, bootstrap skripti
- Design-token pipeline (Style Dictionary → CSS + Dart)

## Out of scope
- Backend/mobil/veb layihələrinin özü (E01, E14, E17–E19)
- Staging/prod deploy (E20)

## Acceptance criteria
- [ ] `docker compose up` ilə bütün dev servisləri qalxır və healthcheck-lər yaşıldır
- [ ] `main`-ə birbaşa push mümkün deyil; PR + 1 approval + yaşıl check-lər tələb olunur
- [ ] Yeni issue avtomatik "QONAQET" board-una `Backlog` statusu ilə düşür
- [ ] Allowlist-də olmayan paket əlavə edən PR `dependency-guard`-da qırılır
- [ ] `tokens.json`-a edilən dəyişiklik həm CSS dəyişənlərini, həm Dart theme-ni yenidən yaradır
