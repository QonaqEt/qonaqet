## Goal
Pullu sosial qonaqlıq: uzaqdan alınan təkliflər, kateqoriya hovuzları, kampaniyalar və adlı/anonim donorluq.

## Scope
Remote/pool/campaign ianələri, adlı-anonim göstərim, hovuz claim-ləri, kampaniyanın bitməsi və qalığın köçməsi, public stats.

## Out of scope
Korporativ CSR kampaniyaları (E10), reytinq xalları (E11).

## Acceptance criteria
- [ ] Hovuz balansı mənfiyə düşə bilmir (paralel claim testi)
- [ ] Kampaniya bitəndə qalıq default hovuza ledger yazısı ilə köçür
- [ ] Adlı donorun adı claim-də proporsional atribusiya ilə düzgün görünür
- [ ] Hovuz və kampaniya ianələri geri qaytarılmır və UI bunu ödənişdən əvvəl yazır
