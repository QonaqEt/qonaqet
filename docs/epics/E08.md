## Goal
Pullu sosial qonaqlıq: uzaqdan alınan təkliflər, kateqoriya hovuzları, kampaniyalar və adlı/anonim donorluq.

## Scope

## Out of scope
Korporativ CSR kampaniyaları (E10), reytinq xalları (E11).

- [x] Hovuz balansı mənfiyə düşə bilmir (paralel claim testi)
- [x] Kampaniya bitəndə qalıq default hovuza ledger yazısı ilə köçür

- [x] Hovuz və kampaniya ianələri geri qaytarılmır və UI bunu ödənişdən əvvəl yazır
