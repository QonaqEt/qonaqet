## Goal
Gənc, canlı və həmrəylik hissi daşıyan public sayt — plus public hədiyyə səhifəsi, reytinq və kampaniya səhifələri.

> ⚠️ "Angular UI guidelines" **PENDING**. `blocked-ui-guidelines` task-ları həmin bölmə gələnə qədər başlanmır.
> İndi yalnız SSR skeleti, routing və token-lər qurulur.

## Scope
SSR skeleti + token-lər (indi), sonra hero + animasiyalar, sayğaclar, bölmələr, hədiyyə səhifəsi,
reytinq, kampaniyalar, developers, formalar, Lighthouse ≥ 90.

## Out of scope
Portallar (E17, E18).

## Acceptance criteria
- [ ] Mobil Lighthouse hər dörd kateqoriyada ≥ 90
- [ ] Layout shift yoxdur; animasiyalar lazy yüklənir və yalnız klientdə işləyir
- [ ] `prefers-reduced-motion` bütün animasiyalarda nəzərə alınır
- [ ] `/g/:token` login olmadan SSR ilə açılır
