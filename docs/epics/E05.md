## Goal
Dinamik kateqoriyalar və ləyaqətli təsdiq prosesi: admin kod dəyişmədən yeni kateqoriya əlavə edə bilsin,
kateqoriyaya bağlı bütün davranış sənəddən gəlsin.

## Scope
Dinamik kateqoriyalar + avtomatik hovuz, silmə qoruması, təsdiq sihirbazı API-si, FIN hash, etibarlılıq müddəti, xatırlatmalar.

## Out of scope
Sosial qonaqlıq axını (E06), hovuz pulu (E08).

## Acceptance criteria
- [ ] Admin yeni kateqoriya yaradanda kod dəyişmədən mobil və vebdə görünür
- [ ] `src/` daxilində heç bir yerdə kateqoriya koduna görə şərt yoxdur (arxitektura testi)
- [ ] Kateqoriya yaradılanda default hovuzu avtomatik yaranır
- [ ] Xam FIN heç yerdə saxlanılmır və loglanmır

## Tasks

### E05-T01 · Kateqoriya aqreqatı və CRUD
- area: backend
- priority: p0
- size: L

- [ ] `code`, `name`, `description`, ikon, rəng, sıra, `isActive`, `isOpen`, `privacyLevel`
