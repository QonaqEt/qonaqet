## Goal
Payriff inteqrasiyası və maliyyə uçotu: hər pul hərəkəti idempotent, tranzaksiyalı, ledger və audit yazısı ilə.

## Scope
Payriff + Fake gateway, callback + yenidən yoxlama, Postgres payments/refunds, ledger + komissiya, payout-lar, uzlaşdırma.

## Out of scope
Hovuz/kampaniya ianələri (E08), partnyor balansı (E13).

## Acceptance criteria
- [ ] Callback itirilsə belə ödəniş 5 dəqiqəlik job ilə təsdiqlənir
- [ ] Eyni ödənişin iki dəfə emalı ikinci ledger yazısı yaratmır
- [ ] Biznes balansı `SUM(amount)` ilə ledger-dən çıxır və Mongo ilə gecə uzlaşdırılır
- [ ] Heç bir məbləğ klientdən qəbul edilmir; hamısı serverdə hesablanır

### E07-T04 · Callback və yenidən yoxlama job-u
- area: backend
- priority: p0

### E07-T05 · Ledger və komissiya
- area: backend
- priority: p0
- size: L

Acceptance:
- [ ] `ledger_entries` append-only; düzəliş yalnız əks yazı ilə olur
- [ ] `source_event_id` unikaldır → consumer idempotentdir
- [ ] Onlayn ödənişli təhvildə `RedemptionCredit` + `Commission` (default 7%, konfiqurasiya olunan) yazılır
- [ ] `BusinessDaily` / `Suspended` üçün komissiya yazılmır
