## Goal
Payriff inteqrasiyası və maliyyə uçotu: hər pul hərəkəti idempotent, tranzaksiyalı, ledger və audit yazısı ilə.

## Scope
Payriff + Fake gateway, callback + yenidən yoxlama, Postgres payments/refunds, ledger + komissiya, payout-lar, uzlaşdırma.

## Out of scope
Hovuz/kampaniya ianələri (E08), partnyor balansı (E13).

## Acceptance criteria
- [x] Callback itirilsə belə ödəniş 5 dəqiqəlik job ilə təsdiqlənir
- [x] Eyni ödənişin iki dəfə emalı ikinci ledger yazısı yaratmır
- [x] Biznes balansı `SUM(amount)` ilə ledger-dən çıxır və Mongo ilə gecə uzlaşdırılır
- [x] Heç bir məbləğ klientdən qəbul edilmir; hamısı serverdə hesablanır
