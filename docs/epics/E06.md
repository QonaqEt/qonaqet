## Goal
"İsmarla" sütunu: biznes günlük təklifləri, askıda məhsullar, claim-lər, atomik kvota və ləyaqəti qoruyan təhvil.

## Scope
Təkliflər (daily/suspended), atomik kvota ilə claim, limitlər, QR/qısa kod, təhvil, müddət bitmə job-u, məxfilik testləri.

## Out of scope
Pullu `Remote` təklifləri və hovuz claim-ləri (E08), ödəniş və ledger (E07).

## Acceptance criteria
- [x] Eyni anda 100 paralel claim cəhdində kvota heç vaxt aşılmır
- [x] Biznes endpoint-ləri alıcının kimliyini heç vaxt qaytarmır (test sübut edir)
- [x] Həssas kateqoriyada staff "Qonaq" etiketini görür, kateqoriya adını yox
- [x] 30 dəqiqədən sonra istifadə olunmayan rezerv avtomatik buraxılır
