## Goal
Bütün backend epic-lərinin üzərində quracağı özül: layerlər, öz CQRS dispatcher-imiz, soft-delete infrastrukturu,
outbox/inbox, cache, scheduler, müşahidə və arxitektura testləri. Heç bir biznes qaydası burada yazılmır.

## Scope
- Solution, layerlər, mərkəzləşdirilmiş paket versiyaları
- SharedKernel: `Result<T>`, `Error`, `Money`, `Clock`, `Guard`, `Entity`, `DomainEvent`, `StronglyTypedId<T>`
- Öz CQRS dispatcher-i və pipeline behavior-ları
- Mongo soft-delete repository + index runner; EF Core + interceptor-lar
- Outbox relay + RabbitMQ + inbox
- Valkey cache / lock / rate limit
- Öz scheduler-imiz, OTel/health, OpenAPI
- Öz arxitektura testlərimiz, öz CSV və QR utilitlərimiz

## Out of scope
- Autentifikasiya (E02), fayllar/email (E03) və bütün domen qaydaları

## Acceptance criteria
- [ ] `dotnet build` warnings-as-errors ilə keçir, `dotnet test` yaşıldır
- [ ] Arxitektura testləri layer qaydalarını və hard delete qadağasını qırılma ilə sübut edir
- [ ] Nümunə use case uçdan-uca işləyir: command → behavior-lar → Mongo tranzaksiya → outbox → RabbitMQ → inbox → Postgres
- [ ] `/health` və OTLP trace-lər Aspire Dashboard-da görünür
- [ ] `docs/dependencies/allowlist.json`-dan kənar paket yoxdur
