## Goal
Admin idarəetməsi və korporativ portal bir Angular tətbiqində, rola görə ayrılmış.

> ⚠️ "Angular UI guidelines" **PENDING**. `blocked-ui-guidelines` task-ları həmin bölmə gələnə qədər başlanmır.

## Scope
Skeleton + auth (indi), sonra bütün admin modulları və korporativ portal.

## Out of scope
Biznes portalı (E17), landing (E19).

## Acceptance criteria
- [ ] Hər siyahıda "silinmişləri göstər" keçidi və bərpa var; qalıcı silmə heç yerdə yoxdur
- [ ] Admin kateqoriya sahələrini kod dəyişmədən qura bilir
- [ ] Korporativ sifariş sihirbazı CSV validasiya hesabatı göstərir
