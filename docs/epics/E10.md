## Goal
Şirkətlərin toplu hədiyyə və bonus göndərməsi, bank köçürməsi ilə ödəniş və şəxsi məlumat sızdırmayan CSR hesabatları.

## Scope
Korporativ hesablar, hədiyyə sifarişləri + CSV validasiyası, bank köçürməsinin təsdiqi, fan-out, PDF/CSV hesabatlar.

## Out of scope
Korporativ portalın UI-ı (E18), reytinqdə şirkət lövhəsi (E11).

## Acceptance criteria
- [ ] 5,000 sətirlik CSV sətir-sətir xəta hesabatı ilə yoxlanılır
- [ ] Ödənişdən sonra hər alıcı üçün bir hədiyyə yaradılır, təkrar işə düşəndə dublikat yaranmır
- [ ] Hesabatda alıcının nə aldığı görünmür — yalnız təhvil verildi/verilmədi
- [ ] Bank köçürməsi admin tərəfindən bank referansı ilə təsdiqlənir

- area: backend
- priority: p1

### E10-T02 · Hədiyyə sifarişi və CSV validasiyası
- area: backend
- priority: p1
- size: L

Acceptance:
- [ ] Şablon: `kind`/`scope`/biznes/məhsul və ya məbləğ, `Corporate` teması, mesaj, brendinq
- [ ] CSV `name,email`, maksimum 5,000 sətir
- [ ] Hər sətir üçün xəta hesabatı (sətir nömrəsi + səbəb) qaytarılır
- [ ] Dublikat email-lər aşkarlanır
- [ ] Ümumi məbləğ = hədiyyə qiyməti × alıcı sayı, serverdə hesablanır

### E10-T03 · Ödəniş: kart və bank köçürməsi
