## Goal
Fayl saxlama, email, PDF və push bildirişləri — E05-dən sonrakı bütün epic-lərin istifadə edəcəyi ortaq servislər.

## Scope
S3 (RustFS) fayl saxlama, öz email şablon mühərrikimiz, Playwright PDF renderer, push göndərici, bildiriş seçimləri.

## Out of scope
Hədiyyə email-lərinin məzmunu (E09), korporativ hesabatlar (E10).

## Acceptance criteria
- [x] Yüklənən fayl RustFS-də dəyişməz açarla saxlanılır və heç vaxt silinmir
- [x] Soft delete olunmuş fayl heç bir endpoint-dən verilmir
- [x] Email-lər Mailpit-də düzgün Azərbaycan hərfləri ilə görünür
- [x] HTML şablonundan PDF yaradılır və korporativ hesabatda işlənir (renderer + `report` şablonu hazırdır; korporativ hesabat özü E10-da bunu işlədəcək)
