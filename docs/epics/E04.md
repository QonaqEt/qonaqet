## Goal
Bizneslərin qeydiyyatı, admin tərəfindən aktivləşdirilməsi, işçi idarəsi, kataloq və coğrafi axtarış.

## Scope
Onboarding + admin aktivləşdirmə, staff membership-lər, kataloq CRUD, biznes parametrləri, geo axtarış, şəbəkələr (bir sahibin bir neçə biznesi).

## Out of scope
Biznes portalının UI-ı (E17), QR təhvil axını (E06/E09).

## Acceptance criteria
- [ ] Müraciət → admin aktivləşdirmə → müraciətçi `BusinessOwner` olur
- [ ] `GET businesses?lat=&lng=&radiusKm=` 2dsphere indekslə işləyir
- [ ] Biznes soft delete olunanda kataloq və təklifləri də soft delete olunur, aktiv claim-ləri ləğv edilir
