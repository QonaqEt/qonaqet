## Goal
"Reytinq": yalnız real qonaqlığın sayıldığı, sui-istifadəyə davamlı və məxfiliyi qoruyan dostcasına yarış.

## Scope
Score consumer-i, anti-gaming qaydaları, Postgres aqreqatları + Valkey ZSET-lər, səviyyələr, nişan job-u, yenidən hesablama.

## Out of scope
Reytinq ekranları (E15, E19), biznes sertifikatı PDF-i (E17).

## Acceptance criteria
- [ ] Xal yalnız təhvil anında yazılır; alınıb istifadə olunmayan hədiyyə xal vermir
- [ ] Özünə hədiyyə göndərmək xal qazandırmır
- [ ] Valkey boşalanda lövhə Postgres-dən yenidən qurulur və eyni nəticəni verir
- [ ] Həssas kateqoriyalar lövhələrdə heç vaxt adı çəkilmir

- priority: p1
- size: L
