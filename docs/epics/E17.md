## Goal
Xidmət təchizatçıları üçün ayrıca Angular tətbiqi: piştaxtada kod yoxlama/təhvil, kataloq, satış, ödənişlər, inteqrasiyalar.

> ⚠️ `CLAUDE.md` → "Angular UI guidelines" bölməsi **PENDING**-dir.
> `blocked-ui-guidelines` etiketli task-lar həmin bölmə doldurulana qədər **başlanmır**.
> O vaxta qədər yalnız skeleton, routing, auth, API client və token-lər qurulur;
> komponent kitabxanası seçilmir və son ekranlar uydurulmur.

## Scope
Skeleton + auth (indi), sonra — UI qaydalarından sonra — təhvil ekranı, dashboard, kataloq, təkliflər,
satışlar, ledger/payout-lar, staff/parametrlər, inteqrasiyalar, brend bölməsi.

## Out of scope
Admin və korporativ portal (E18), landing (E19).

## Acceptance criteria
- [ ] Skeleton build olunur, lint və testlər yaşıldır
- [ ] Rənglər və şriftlər yalnız design token-lərdən gəlir; hard-code hex yoxdur
- [ ] UI qaydaları gəlməyincə heç bir komponent kitabxanası quraşdırılmır
- [ ] Təhvil ekranı həm webcam QR, həm USB skaner, həm əl ilə kod ilə işləyir
